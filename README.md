
# AI Technology Stack

这是山东大学智能创新研究院（Academy of Intelligent Innovation）开发的AI技术栈文档，旨在提供全面的AI技术知识体系。

## 在线阅读

您可以通过以下链接访问在线文档：
[AI Technology Stack](https://aii-sdu.github.io/AI-Technology-Stack/)

## 项目简介

本文档使用 mdBook 构建，提供了系统化的AI技术栈知识内容。

## 本地构建

1. 安装 Rust 和 mdBook
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
cargo install mdbook
```

2. 克隆仓库
```bash
git clone https://github.com/aii-sdu/AI-Technology-Stack.git
cd AI-Technology-Stack
```

3. 构建文档
```bash
mdbook build
```

4. 本地预览
```bash
mdbook serve
```

然后在浏览器中访问 `http://localhost:3000`
